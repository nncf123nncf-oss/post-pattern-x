# 型ばらし（post-pattern-x）

気になる投稿を貼ると、書き出しの型・行ごとの役割・締めの型・長さを分けて見せる静的ページです（100日100プロダクト Day071）。最後に、型の並びだけを「骨組み」として取り出せます。

- 貼った文はブラウザの中だけで処理し、サーバーには送信せず、保存もしません（通信は閲覧数の計測のみ）
- AIは使っていません（言葉のパターンによるルールベース）
- 伸びた理由は分かりません。型の特徴を分けて見せるだけで、「この型だから伸びた」とは言えません
- 型の見分けは目安で、外れることがあります。骨組みには貼った文の言葉を入れません
- ユニット数（280は目安）は相手の投稿の長さの参考値です

## 使い方
`index.html` をブラウザで開き、投稿を貼ります。ビルド不要（1ファイル）。

## 開発用（source/）
- `index.src.html` と `wide-ranges.txt` から `build.py` が `index.html` を作ります（文字幅の表を埋め込むため）
- `run-checks.js`: 型の見分けの検算（`node source/run-checks.js`）。`make-corpus.py` が作る `corpus.json`（Pythonの文字幅）と数え方を照合
- `e2e.js`: 実ブラウザ（Chrome headless）での検算。`shoot.js`: 投稿カード用の画面撮影
